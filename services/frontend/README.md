# 企业智能体平台前端

前端已迁移到 Vue 3 + TypeScript + Vite，生产容器使用 Node 多阶段构建并由 Nginx 提供静态资源和 `/api/` 反向代理。

当前页面包含：

- 登录、退出和修改密码；
- 工作台与处理链路概览；
- 知识库、文件夹、批量上传、下载、移动、切片查看、重建索引、删除和归档；
- 智能体列表、限定知识库/文件夹范围的问答和引用展示；
- 平台管理员的账号、部门和审计管理；
- ERP、PLM、MOM 系统连接占位。

认证使用 HttpOnly Cookie，页面只负责展示和操作入口。知识库、文档和智能体的部门权限由 API 在每次请求时强制校验，浏览器提交的部门字段不能扩大权限。

本地开发：

```bash
npm ci
npm run dev
```

生产构建验证：

```bash
npm run build
```
